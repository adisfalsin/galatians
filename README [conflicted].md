# Study of the Book of Galatians

Bilingual (English / Brazilian Portuguese) verse-by-verse study site.

## After uploading to GitHub Pages

Once your site is live, open each .html file and replace the placeholder:

    YOUR_GITHUB_PAGES_URL

with your actual URL, for example:

    https://johnsmith.github.io/galatians-study

This makes WhatsApp/social share previews show the postcard image.
There are 4 files to update (galatians-313.html, galatians-313-pt.html,
galatians-518.html, galatians-518-pt.html) — each has it once near the top.

## GitHub Pages setup
1. Upload all files (not the folder) to a public repository root.
2. Settings → Pages → Source: main branch / (root) → Save.
3. Live at https://YOUR-USERNAME.github.io/REPO-NAME/
