# Study of the Book of Galatians

A bilingual (English / Brazilian Portuguese) verse-by-verse study site.

## Pages
- `index.html` — English landing page
- `index-pt.html` — Portuguese landing page
- `galatians-518.html` / `galatians-518-pt.html` — Galatians 5:18 study
- `galatians-313.html` / `galatians-313-pt.html` — Galatians 3:13 study
- `*-postcard-*.png` — downloadable summary postcards

## Publishing on GitHub Pages
1. Create a new public repository and upload all files in this folder.
2. Go to **Settings → Pages**.
3. Under **Source**, choose branch `main` and folder `/ (root)`, then **Save**.
4. Your site goes live at `https://YOUR-USERNAME.github.io/REPO-NAME/`

The English landing page (`index.html`) is the entry point. The 🇬🇧 / 🇧🇷 flags
in the corner switch between languages on every page.
